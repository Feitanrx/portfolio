# Portfólio Pessoal — João Marcos Ferreira

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, meus conhecimentos em desenvolvimento de software e meus projetos práticos.

O projeto faz parte da minha transição de carreira para a área de tecnologia e tem como objetivo reunir informações profissionais e facilitar o acesso aos meus projetos e redes de contato.

## 🌐 Acesse o projeto

**[Visualizar portfólio](https://portifolio-omega-three-97.vercel.app/)**

## ✨ Funcionalidades

- Apresentação pessoal e resumo profissional.
- Seção sobre minha trajetória e transição para a área de tecnologia.
- Links para redes profissionais e projetos.
- Interface voltada à apresentação de informações profissionais.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- HTML5
- CSS3

## 🚀 Como executar localmente

Pré-requisitos: Node.js e npm instalados.

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd NOME_DO_PROJETO
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse o endereço local informado pelo terminal.
